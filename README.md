# ⛳ Golfer Experience Quiz

A simple, interactive web application to determine a golfer's experience level through 5 targeted questions.

## Features

- 5 carefully crafted questions covering:
  - Playing frequency
  - Handicap/scoring ability
  - Years of experience
  - Club proficiency
  - Professional instruction history

- Experience levels:
  - **Beginner** (0-4 points)
  - **Intermediate** (5-9 points)
  - **Advanced** (10-12 points)
  - **Expert** (13-15 points)

- Clean, responsive design
- Progress tracking
- Detailed results with personalized descriptions

## How to Use

1. Open `index.html` in any modern web browser
2. Answer all 5 questions by clicking your preferred option
3. Navigate using "Next" and "Previous" buttons
4. View your experience level and personalized description
5. Retake the quiz anytime with the "Take Quiz Again" button

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Quiz logic and interactivity

## No Dependencies

This is a pure HTML/CSS/JavaScript application with no external dependencies or frameworks required.
